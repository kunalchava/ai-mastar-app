# CIPHERX AI + PAGER-X (Android, Capacitor)

The app has **no demo or simulated data**. It shows only what your own endpoints return and
displays real connection states (Not configured / Connecting / Connected / Error).
Until you configure endpoints in **Settings**, panels are empty.

## Build the APK on GitHub
1. Create a GitHub repo and push this folder to `main`:
   `git init && git add . && git commit -m "init" && git branch -M main && git remote add origin <repo-url> && git push -u origin main`
2. Open the repo's **Actions** tab, then the **Build Android APK** run (or click *Run workflow*).
3. When it finishes, download the **cipherx-debug-apk** artifact (a zip containing `app-debug.apk`).
4. Copy the APK to your phone and install it (allow "Install unknown apps"). The debug APK is signed
   with the standard Android debug key, which is installable. For Play Store use, create a release keystore.
5. Optional: push a tag (`git tag v1.0.0 && git push --tags`) to also get the APK attached to a GitHub Release.

Change the package ID in `capacitor.config.json` (`appId`) before publishing.
The `android/` folder is generated by CI; commit it if you want to customize native files.

## Endpoints the app calls (you provide the backend)
Base URL = orchestrator. Optional token is sent as `Authorization: Bearer <token>`.

| Request | Expected JSON |
|---|---|
| `GET {base}/api/status` | `{"master":{"state":"Online"},"agents":{"active":14,"total":16},"squads":[{"name":"Security","health":95}],"jobs":{"running":12,"queued":3,"completed":842},"health":98,"security":{"level":"Guarded","critical":0,"high":2,"medium":5,"low":11},"activity":[{"ts":"2026-01-01T09:42:00Z","level":"ok|info|warn|error","text":"..."}]}` |
| `GET {base}/api/{section}` | Any JSON: array of objects becomes a table, object becomes key/value rows. Sections: `ai agents squads auto jobs mon proj pager wifi net hw re sec mem reports` |
| `POST {base}/api/assistant` | body `{"message":"..."}`, reply `{"reply":"..."}` |
| Device `GET {url}` | `{"state":"Connected","ip":"192.168.4.21","mode":"Relay"` or `"uptime":"3d 2h","cpu":34,"ram":52}` |
| Device `POST {url}/command` | body `{"command":"..."}`, any JSON reply |
| Telemetry WebSocket | messages `{"cpu":0-100,"ram":0-100,"net":0-100}` |

Missing fields display as an em dash; failures display the error. Nothing is ever substituted.
Native HTTP (CapacitorHttp) is enabled so requests to local devices are not blocked by CORS.
Exports (JSON/CSV) use the live snapshot and open the Android share sheet.
